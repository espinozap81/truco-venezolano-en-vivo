# Truco Venezolano en Vivo

Prototipo con baraja española de 40 cartas. Actualmente utiliza datos y monedas de demostración. Supabase todavía no está integrado.

## Cloudflare Workers

- Nombre: truco-venezolano-en-vivo
- Directorio raíz: raíz del repositorio
- Comando de compilación: dejar vacío
- Comando de despliegue: npx wrangler deploy
- Archivos estáticos: dist (configurado en wrangler.jsonc)

Subir la carpeta dist y los archivos de la raíz, no el ZIP.
